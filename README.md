# Daily Commodity Brief — Version 1

This is a front-end prototype for dailycommoditybrief.org.

## Included
- WTI, Brent, RBOB and Henry Hub market cards
- Daily move / percentage change layout
- Biggest-move explanation
- WTI chart placeholder
- Futures-curve section
- Market-driver sections
- Daily article section
- Trader Takeaway

## Important
The figures and article text in this prototype are sample/illustrative data. The next build should connect:
1. A market-data API
2. A news/search workflow
3. A small database or JSON feed
4. The daily 6 PM Central automation
5. Your dailycommoditybrief.org domain

Open `index.html` locally to preview the dashboard.
